# Created-creature variety: original and remake

September 10, 2026. This comparison concerns the creature creator, not the scientific species roster.

## Direct emulator observations

Booted the Windows original at [ClassicReload](https://classicreload.com/play/win3x-odell-down-under.html), entered Create-A-Fish, changed Small to Large with the keyboard, selected Electric Shock, and entered live reef play. The large spotted green body appeared in both preview and reef. A low-health cleaner-fish warning appeared during that life.

The visible editor contains five swatches (green, pink, yellow, red, blue), speed/endurance/agility sliders, size and special-ability lists, name and day/night controls, a live preview, and a points budget. No independent mouth, head, fin, or tail selector is visible. This is an observation of this editor, not a claim about every historical release.

Evidence: `artifacts/original-creator-large-2026-09-10.png`, `original-creator-electric-2026-09-10.png`, `original-created-fish-reef-2026-09-10.png`.

**Direct-test limit:** the emulator accepts keyboard control but its pointer remains stationary when browser clicks are sent. Color changes and slider-driven body changes were not directly verified. Earlier attempts to use native browser control stopped because automatic review could not reliably determine the browser URL; the successful observations above use the supported in-app browser with its explicit URL.

## Documentary evidence

The original Windows User's Guide, page 7 (local reference `C:/Users/Daniel/Desktop/odell-reference/original-windows-manual.txt`, lines 170 onward), explains that swimming traits reshape the fish: speed favors slender acceleration, endurance favors streamlined cruising, and agility favors a disk body with surrounding fins. This is documentary evidence rather than a successful slider playtest.

## Remake before and after this work

| Appearance dimension | Previous remake | Current implementation |
|---|---|---|
| Body | Three recolored species paintings | Three painted body cores with trait-driven or freely chosen proportions |
| Tail | Part of the original painting | Fan, fork, lyre, tapered |
| Back fin | Part of the painting | Low, sail, spiny, ribbon |
| Side fins | Part of the painting | Paddle, wing, pointed |
| Mouth/head | Part of the painting | Small, wide jaws, beak, long snout |
| Color | One 60% whole-image tint | Separate RGB body, fin and marking colors, retaining painted light and texture |
| Pattern | Fixed source pattern | Plain, spots, lengthwise stripes, bands, dark back |
| Motion | Borrowed species rig | Articulated painted tail, dorsal, side fins and jaw; turn, braking, feeding and inflation responses |

The previous remake missed the original's meaningful link between traits and appearance. The current creator restores that principle and adds explicit modular choices beyond the original interface observed here. Those choices are invented creatures, not scientifically valid species. Cosmetic mouths and fins do not silently alter diet, protection, swimming statistics or point cost; the adjacent life controls remain authoritative.

Old saved fish retain their legacy painting when resumed. An edited variation adopts the new appearance system; it remains detached from its parent fish. New anatomy survives test/revise/keep, shelf/reload/resume, and portable saves, with mismatched modern appearance metadata rejected.

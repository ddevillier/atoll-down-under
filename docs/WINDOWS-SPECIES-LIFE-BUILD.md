# Species Life — Windows testing candidate

September 7, 2026. Planned portable archive: `dist/Atoll-Down-Under-Windows-Species-Life-2026-09-07.zip`.

This candidate combines the Living Reef artwork/animation with 19 optional species adventures and 57 Practice choices. It includes cleaner care, shared sand discoveries, renewing grazing patches, companion feeding trips, school feeding waves and short ambush strikes. Normal mouse swimming now brakes near the destination so fish settle instead of circling it indefinitely.

See [Ways of living](SPECIES-LIFE.md) for the activities and controls. Extract the whole application folder and open `Atoll Down Under.exe`. The game starts fullscreen; F11 changes display mode, and Escape pauses for inspection. No server or account is required to play.

# Windows Species Adventures testing build

September 7, 2026. The intended portable archive is `dist/Atoll-Down-Under-Windows-Species-Adventures-2026-09-07.zip`. Extract the complete folder and open `Atoll Down Under.exe`. F11 toggles fullscreen; Escape pauses. Older Family Journal and earlier archives are preserved.

## What to try

Practice now offers Try adventure for Yellowtail fusilier, Orange coral goby, Longhorn cowfish and Cuttlefish. E performs the contextual action. Keep following the fusilier school; visit and return to a goby home; uncover and eat at two cowfish sand sites; become still on two cuttlefish backgrounds. Explore freely preserves the same abilities with optional prompts. Discoveries persist in the Family Journal.

Open a creature in the Field guide and select Play introduction for an optional short naturalist narration. Stop, close or switch creatures to end it. All 64 clips are local; no API key or internet connection is needed while playing. Narration has a separate Settings volume and temporarily lowers the music.

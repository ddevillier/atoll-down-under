# Resident and specialist animation strategy

Read-only review, 7 September 2026. Scope: s19, s43–s47, s60–s63. Reviewed current `animal-profiles.js`, `articulated-motion.js`, `motion.js`, `render.js`, `ground-motion.js`, `simulation.js`, `sprite-assets.js`, the ten natural-history records, and actual `artifacts/sprite-sheet-{1,2,3}.png` paintings. This is an implementation strategy, not a completion record. No new original-game research or biological claims are needed for this scope.

## Main finding

The continuous mesh is a good way to keep the existing painted surfaces joined, but its family branches are not yet ten accepted animations. Several fields animate a broad rectangular region that contains both an appendage and a rigid structure. Some visible behaviors cannot drive the renderer at all: bottom-resident feeding updates only prose; the holdfast branch returns before feeding. A profile row is configuration, not an observable life.

The biggest visual gains here come from selective stillness. An unchanging snail shell above a traveling foot, a fixed seahorse tail below a moving head, and a firm anemone base below responsive tentacles communicate more than additional whole-sprite distortion. Shared `poseFor` pitch and squash, and the horizontal compression used for facing changes, currently undermine those differences. These should be disabled or replaced for attached animals, shelled animals, radial animals and the front-facing crab.

## Implementation order and shared state

1. **Make anchor protection real.** Add per-painting landmarks and masks, draw an authoring overlay in the developer gallery, and suppress shared whole-body deformation for grounded/attached/armored cases. Keep the existing continuous mesh for joined surfaces; use local masked transforms only where overlapping painted appendages cannot be separated with smooth fields. Do not promise articulated joints absent from the painting: small honest motion is better than invented anatomy.
2. **Wire behavior to motion.** Bottom feeding must set action phase/activity; holdfast animals need a local update rather than an early return. Define finite phases (approach, settle, handle, resume) and normalized progress from simulation time. Pause freezes phases. Render reads state and never consumes food, awards progress or assigns clients.
3. **Separate ground contact from sprite center.** A ground route defines a support position. A per-animal contact offset places the shell/foot/base correctly; feeding rotates upper structures around that contact. Smooth at route corners. Reflection at route ends must not make radial residents squeeze through a fake turn.
4. **Reuse ecological priorities.** Cleaner assignment and safety take priority over flavor motions. Most of these species are solitary, attached, or opportunistic; social uplift means relationships and tolerances, not universal schooling. Attach host IDs only when a living compatible resident exists; avoid extra population.
5. **Drive local environmental reactivity from simulation.** Bounded neighbor checks on a staggered low-frequency schedule set alert strength or orientation; decay continuously. A shared current phase can drive tentacles, antennae and plumes with local differences. Do not use a random render-time twitch on each frame.

Useful motion state: `activity`, `activityPhase`, `activityProgress`, `locomotionEffort`, `alert`, `contactAnchor`, `lookAt`, `hostId`/`clientId` only where applicable. Reuse existing valid state where possible. Every added persistent field needs finite-value validation, default behavior for old saves and cleanup on death/respawn/travel. A cosmetic phase can instead derive from stable entity ID and simulation time.

## Verification that proves this scope

- A ten-species review matrix records actual observations for rest, locomotion, feeding, reaction and reversal/return; unavailable states are explicitly justified. Capture a short animated sequence, not one attractive frame.
- View each at normal game size and enlarged inspection size, with the support point/core outline overlay available. Check attachments, eyes, shell rigidity, paint stretching, triangle seams and thin appendage continuity.
- Run actual generated habitats as well as the gallery: a cleaner session; meadow seahorse feeding; crab/snail/nudibranch reachable meals; attached anemone near anemonefish; cuttlefish feeding and concealment interruption.
- Test all phase changes under pause, reduced motion, save/restore, entity removal, respawn, habitat travel and alert cancellation. Reduced motion retains clear static food/cleaning cues and does not erase the behavior's meaning.
- Include the specialist meshes in the busy-scene performance run. Their thin alpha-heavy shapes and masked layers cost more than a fish strip. Current cache key uses unbounded absolute animation ticks, so phase frames are not reused across later cycles; do not infer a bounded cache alone proves acceptable CPU/frame time. Measure misses and frame timings during motion, then choose resolution/phase quantization appropriate to ordinary display size.
- Do not mark this scope complete from configured profiles, unit deformation samples, or a static contact sheet alone.

## Source boundary

All behavior facts above come from the existing ten `NATURAL_HISTORY` entries and their cited Australian Museum, NOAA, Oregon Coast Aquarium, University of Michigan and Western Australia DBCA sources. Pairing, attachment, parasite cleaning, tube feet and the relevant body structures are supported at the identity level stated there. Timing, local alert reactions, route choices, exact appendage phases and representative diet handling are authored game behavior. Unidentified group labels must retain that distinction in the guide.

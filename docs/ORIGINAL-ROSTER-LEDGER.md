# Original Windows roster reconciliation

Primary evidence: the archived Windows 3.1 game at [Internet Archive](https://archive.org/details/ODELL_201905), downloaded from its ODELL.zip link. Original binaries and extracted text remain in the external `odell-reference` research folder; none are bundled into the remake.

## What this establishes

The original INFORES.DLL contains 104 field-guide names at string IDs 64–167. Their scientific labels appear at name ID + 104, English lengths at +208 and metric lengths at +312. This inventory includes coral types and other nonplayable organisms. It does not establish the number of playable species or Tournament order. ODELL.EXE separately contains organism labels at 1101–1182, including a Missing Image placeholder; resource order is not play order.

The original Windows resources confirm a cleaner mimic blenny (name ID 81, scientific label 185, information resource 517), giant clam, brittle star, lobster and sea wasp. Those audit leads are now supported by primary Windows content. Their actual behaviors and spawn rules still need execution evidence.

They also confirm several identity mismatches in our researched catalog: the original coral grouper is Cephalopholis miniata; the butterflyfish is Forcipiger flavissimus; the longfin spadefish is Platax teira; the lyretail coral trout is Variola louti. These differ from the species our current entries describe. Completed factual coverage is therefore not completed roster fidelity. Current text should not be relabeled while retaining an incompatible animal illustration or description.

Historical scientific labels below are transcribed as evidence, including apparent misspellings and obsolete names. They are not recommended modern taxonomy. A different string can be a synonym or spelling error rather than a different organism; that needs authoritative biological verification.

## Gameplay correction supported by this evidence

INFORES.DLL RCDATA resource 547 describes fish, crab and shrimp as lionfish food. Crab was missing from our diet. It is now available through the existing size/armor rules to player and NPC lionfish and the shared food-web view. Saved lionfish receive this one diet correction on restoration without changing positions, populations or RNG; custom fish retain their chosen diets. A real meal-approach simulation and saved-state comparison pass, along with the full 115-test unit/asset suite.

The same resource names very large fish as lionfish enemies, contradicting a blanket claim that the original guide grants predator immunity. Our universal poison exclusion remains an open behavior gap. It is not changed in this revision under the gentle-difficulty direction. The original resource does not settle daytime/nighttime rules. Great-white information resource 541 describes a broad diet but is insufficient to prove the specific sponge exception from the secondary walkthrough.

## Reproduction and limits

Files are 16-bit NE resources. Read the NE header offset from DOS header 0x3c, then the relative resource-table offset at NE +0x24. Each table gives its alignment shift and typed resource records. RT_STRING (type 6) blocks contain sixteen length-prefixed byte strings; string ID = (block ID − 1) × 16 + slot. INFORES name strings pair with the three fixed offsets above. Its RCDATA (type 10) information ID = name ID +436. Check names and sampled sections rather than assuming raw byte matches are correctly associated.

This is static inspection, not execution of the original. Exact numeric balance, animations, layout adjacency and Tournament order remain unverified. Original educational paragraphs have not been copied into product content. The parked Windows Saves ZIP precedes the lionfish correction.

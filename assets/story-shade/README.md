# Shade presentation provenance

The runtime renderer reuses the active habitat painting and the existing bloodspot squirrelfish illustration. Its cached foreground matte is derived from those original pixels at their same world coordinates. No additional image asset is loaded.

See `provenance.json` for species identity, source material and accessibility boundaries. Painted presentation fixtures and their reproducible inspection script are development evidence in `artifacts/species-adventures/shade/`; they are not runtime assets or proof of completed gameplay acceptance.

# Coral Housekeeper painting

`pocillopora-damicornis-v1.png` is the runtime transparent painting of the named *Pocillopora damicornis* colony. Its generated alpha is preserved. The renderer samples this painting to constrain sediment to existing coral surfaces; clearing reveals the original polyps and branches.

[provenance.json](provenance.json) records the generator, exact prompt, style reference, source path, taxonomic references, processing and validation.

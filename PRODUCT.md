# Atoll Down Under

<!-- impeccable:product-schema 1 -->

## Platform
web

## Stack
Desktop-first Electron application with a Canvas 2D game renderer and local ES modules. Implementation choice under the user's instruction to create the project. Browser serving is a development/test surface, not a public website.

## Users and purpose
An offline widescreen life-science exploration game for the user and players who enjoy the ecological learning and varied creatures of Odell Down Under. The user selected a Windows presentation reference, full playable widescreen scenes, and the name Atoll Down Under.

## Capabilities and constraints
Nine connected reef sections. Practice, Challenge, Tournament, and Create-a-Fish. Species diets and predators, energy, parasites and cleaning, hiding, day/night populations, special abilities, educational guide, scoring, local saves and leaderboards. Original relaxing music and sound effects. New artwork, text, music and branding; no bundled original game assets.

## Evidence
Prior research read the original Windows manual and inspected Windows/Macintosh screenshots. Exact original numerical constants are not verified. This project recreates major mechanics with independently authored data and balancing.

## Principles
Preserve ecological decisions, make each species feel different, retain full daytime readability at night, make the entire ecosystem inspectable, and keep the game playable offline.
